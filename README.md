# 💰 Employee Salary Prediction Using Random Forest

## 📌 Project Overview

This project focuses on predicting employee salaries using Machine Learning techniques, particularly the Random Forest Regression algorithm.

The objective is to analyse employee-related factors and develop a predictive model that estimates salaries based on relevant features.

## 🎯 Project Objectives

- Analyse employee salary datasets.
- Perform data cleaning and preprocessing.
- Explore relationships between employee features and salaries.
- Build a Random Forest Regression model.
- Evaluate model performance.
- Generate salary predictions.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## ⚙️ Machine Learning Workflow

1. Dataset Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Train-Test Split
6. Random Forest Regression
7. Model Evaluation
8. Salary Prediction

## 📊 Model Evaluation

The model will be evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## 📁 Project Structure

- `dataset/` – Employee salary dataset
- `notebooks/` – Data analysis and model development
- `models/` – Trained machine learning model
- `images/` – Project visualizations

## 🚀 Future Improvements

- Add feature importance visualizations.
